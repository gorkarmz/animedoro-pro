# UI Design Rules

- **Zero Emojis**: Do not use unicode emojis in any user interface text, headers, labels, or buttons.
- **Icon Libraries**: Always use SVG vector icon components from `lucide-react` with proper sizing and stroke widths.
- **Character Imagery**: Incorporate high-resolution imagery and thematic elements for Luffy (One Piece), Asta (Black Clover), Naruto (Naruto), Meliodas (Nanatsu no Taizai), and Ippo (Hajime no Ippo).
